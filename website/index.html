Private by architecture

Your chats never leave the browser.

Skeinos indexes everything locally. There is no account, no telemetry, and no analytics: not opt-in, not off-by-default, none at all. In normal use the extension makes no network requests.

You can check that yourself. Skeinos is open source under GPL-3.0, so the code that reads your conversations is public. Read it, review every permission it asks for, or build the extension from source and run that instead.

Questions

Good to know.

Is Skeinos free?
Yes. The full organization, search, and prompt library is free, and no account is required.
Does my conversation data leave my device?
No. Conversations are stored and searched locally in your browser, and with no account and no telemetry there is nothing to upload. Skeinos makes one kind of network request, ever: when a chat site changes its layout, it downloads a small file of corrected page selectors so the sidebar keeps working. That download carries no cookies, no identifiers, and nothing about you or your chats.
Is Skeinos open source?
Yes, under the GPL-3.0 license, at github.com/aakkagam/skeinos. GPL-3.0 means anyone can read, modify, and redistribute it, and that any fork has to stay open source too. If a chat site changes and breaks the sidebar, the fix is usually one small file, so you can send a patch instead of waiting for us.
Which browsers and AI sites does Skeinos support?
Skeinos runs on Chrome and Firefox and works on Claude, ChatGPT, Gemini, and Perplexity. It is built on Manifest V3, with more platforms on the way.
